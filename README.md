## 🎮 Projeto em destaque

### 🚀 PlayNext

Plataforma de descoberta de jogos criada para ajudar usuários a encontrar
novos títulos através de uma experiência rápida e personalizada.

O projeto utiliza um feed de trailers e recomendações baseadas nas
preferências e interações do usuário.

**Principais tecnologias:**

`Flutter` • `Dart` • `Node.js` • `TypeScript` • `PostgreSQL` • `Prisma`

🔗 [Ver projeto no GitHub](https://github.com/lucasrivolta-dev/Projeto-PlayFind)
